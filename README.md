# 🛍️ Clothing Brand E-commerce

E-commerce web application developed for my personal clothing brand using Angular.

## 📌 Overview

This project is the foundation of my brand's online store.  
It is being built as a scalable and modern front-end application to display and sell clothing products.

The focus is on:
- Clean and maintainable architecture
- Performance and responsiveness
- Real-world application structure

---

## ✨ Current Features

- Product listing page  
- Dynamic product rendering  
- Product cards (image, name, price)  
- Responsive grid layout  
- Organized Angular structure (features, services, models)  

---
